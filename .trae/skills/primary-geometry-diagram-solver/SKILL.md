# 小学几何画图解题 Skill

## 适用场景

当用户提出小学阶段“平面图形、立体图形、图形运动、几何画图解题、看图列式、拍照识别几何图形、补辅助线、求周长/面积/表面积/体积”等问题时使用本 Skill。

目标不是只给公式，而是先把题意转成清楚的课本风格图形，再用图形关系解决问题。

## 统一画图入口

- 小学几何题、几何图片识别题、看图求面积/周长题，统一使用本 Skill 作为唯一画图规则底座。
- 画图前必须先匹配本 Skill 中的图形类型、题型规则和 SVG 渲染兼容规则，再生成图形。
- 不要脱离本 Skill 临时自由绘图；如果现有规则不足，先补充本 Skill 规则，再按补充后的规则画图。
- 每次画图都要优先保证题目给出的几何关系真实成立，例如垂直、平行、等长、直径、半径、高、底边、辅助线位置。
- 生成图形时优先输出课本风格、手机端清晰可见的图：线条粗、点清楚、标注少而准、公式放在图下方。

## 总原则

- 先判断图形类型，再画图，不要一开始套公式。
- 图形必须服务于解题：保留已知量、未知量、关键关系和必要辅助线。
- 小学阶段优先使用直观图：长方形、正方形、三角形、平行四边形、梯形、圆、扇形、组合图形、长方体、正方体、圆柱、圆锥。
- 标注要简洁：已知量写数值，未知量用 `?`，单位保持原题单位。
- 辅助线必须有理由：用于“割、补、拼、移、转、展开、投影、等底等高、转化为熟悉图形”。
- 如果图片或题干信息不全，先说明需要核对的地方，再给出基于可见信息的解法。

## 输出结构

回答几何题时推荐按下面顺序：

1. 题意转图：说明这是哪类图形问题。
2. 已知条件：列出边长、半径、直径、高、角度、圈数、层数等。
3. 画图要点：说明应画什么图，标哪里，是否加辅助线。
4. 解题思路：把复杂图形转化成基础图形。
5. 列式计算：一步一步写，单位清楚。
6. 答：给出最终结果。

如果前端支持结构化图形，优先输出可绘制的 `diagram` JSON。

## 可绘制图形 JSON 规范

用于平面图形、立体图形示意图、辅助线、展开图和变换图。

```json
{
  "analysis": {
    "已知条件": ["条件1", "条件2"],
    "所求问题": "求什么",
    "思路": ["步骤1", "步骤2"]
  },
  "diagram": {
    "w": 360,
    "h": 240,
    "els": [],
    "aux": []
  },
  "steps": []
}
```

图元规则：

- `poly`：多边形，`pts=[[x,y]...]`。
- `seg` / `line`：线段，`x1,y1,x2,y2`。
- `ray`：射线，`x1,y1,x2,y2`。
- `circle`：圆，`cx,cy,r`。
- `arc`：圆弧，`cx,cy,r,a0,a1`。
- `pt`：点，`x,y,label`。
- `len`：长度标注，`x1,y1,x2,y2,text`。
- `angle`：角度标注，`cx,cy,r,a0,a1,text`。
- `txt`：文字标注，`x,y,text`。
- `aux`：辅助线数组，写法同 `seg`、`line`、`ray`，通常用虚线。

画图要求：

- 坐标要能真实拼出图形关系，不要随意摆放。
- 重要边、底、高、半径、直径、角度要标出来。
- 组合图形要能看出“分割”或“拼补”过程。
- 立体图形要用斜线或虚线表现看不见的棱。
- 变换题要在 `steps` 中给出变换前后图，如平移、旋转、切割、拼补。

SVG 渲染兼容规则：

- 几何图优先使用清晰描边，不要大面积纯色填充盖住内部辅助线和标注。
- 如果需要区分阴影区域，只使用浅色透明填充，如 `rgba(124,58,237,0.10)` 或 `rgba(5,150,105,0.10)`。
- 不要在 SVG 的 `fill`、`stroke` 等属性里直接写 `color-mix(...)`，部分手机端会渲染失败并默认显示为黑色。
- 文字、点、线、辅助线必须始终可见；深色填充区域上不要放黑色文字。
- 答案和关键列式不要放在底部悬浮按钮可能遮挡的位置，图形下方至少留出安全空白。
- 手机端几何图不要使用过大的 `viewBox` 导致图形缩得太小；小学几何示意图优先使用 `viewBox="0 0 360 260"` 或接近比例。
- 主体线段 `stroke-width` 不小于 `3`，辅助线不小于 `2`，点半径不小于 `4`，否则手机端容易只看到文字和点。
- 图中说明文字要少而大，避免把公式、长句都塞进 SVG；公式和推理放在图下方文本区域。
- 画图时先保证“图形轮廓清楚”，再添加颜色；不能依赖颜色表达主要几何关系。
- 手机端截图或对话流中，图形顶部可能被应用标题栏、展开按钮遮住；SVG 顶部必须预留安全空白，主体图形不要贴近 `viewBox` 顶边。
- 重要尺寸标注（如高、直径、角度、问号）不要放在图形最顶部或右上角悬浮按钮附近，优先放在图形内部或下方安全区域。

## 平面图形范围

### 线、角、位置关系

包括线段、直线、射线、角、直角、锐角、钝角、平行、垂直。

画图规则：

- 点用字母标，如 `A`、`B`、`C`。
- 线段要标两端点和长度。
- 平行线要保持同向，垂直线要画出直角标记。
- 角度题要画角弧，已知角标数值，所求角标 `?`。
- 如果题目给出 `AE⊥BC`，并且把 `BC` 画成水平底边，则 `A` 和 `E` 必须上下对齐，`AE` 必须画成竖直线，`E` 是从 `A` 向 `BC` 作垂线的垂足。
- 如果题目给出 `DC⊥BC`，并且把 `BC` 画成水平底边，则 `D` 和 `C` 必须上下对齐，`DC` 必须画成竖直线。
- 不能只在文字里写“垂直”，图中却把对应线段画成斜线；垂直关系必须在坐标和直角标记中同时体现。

解题关注：

- 直角是 `90°`。
- 平角是 `180°`。
- 周角是 `360°`。
- 三角形内角和是 `180°`。

### 长方形和正方形

常见问题：周长、面积、拼接、剪去、重叠、跑道直道部分。

画图规则：

- 长方形标长和宽。
- 正方形标边长。
- 周长问题强调“围一圈”。
- 面积问题强调“铺满一面”。

公式：

- 长方形周长：`(长 + 宽) × 2`
- 长方形面积：`长 × 宽`
- 正方形周长：`边长 × 4`
- 正方形面积：`边长 × 边长`

### 三角形

常见问题：面积、等底等高、分类、补成长方形/平行四边形。

画图规则：

- 必须标出底和对应的高。
- 高要从顶点垂直到底边或底边延长线。
- 面积题不要只标三条边，必须标底和高。

公式：

- 三角形面积：`底 × 高 ÷ 2`

转化思想：

- 两个完全一样的三角形可拼成一个平行四边形。
- 等底等高的三角形面积相等。

### 平行四边形

常见问题：面积、割补成长方形。

画图规则：

- 标底和对应高。
- 高必须垂直于底，不是斜边。
- 辅助线通常从顶点向底作垂线，割下一个三角形平移到另一边。

公式：

- 平行四边形面积：`底 × 高`

转化思想：

- 平行四边形可以割补成长方形，面积不变。

### 梯形

常见问题：面积、上底下底高、拼成平行四边形。

画图规则：

- 标上底、下底和高。
- 高是两条平行底之间的垂直距离。
- 不要把腰当高。

公式：

- 梯形面积：`(上底 + 下底) × 高 ÷ 2`

转化思想：

- 两个完全一样的梯形可拼成一个平行四边形。

### 圆

常见问题：周长、面积、半径、直径、半圆、跑道、圆环。

画图规则：

- 标圆心、半径或直径。
- 半圆问题要看清是否包含直径这条边。
- 两个半圆合起来是一个圆。
- 跑道由两条直道和两个半圆组成时：两个半圆合成一个圆，圆的直径等于长方形的宽。跑道边界只包括上直道、下直道、左半圆弧、右半圆弧；不要把长方形左右两条宽画成实线跑道边界。

公式：

- 直径：`d = 2r`
- 圆周长：`C = πd = 2πr`
- 圆面积：`S = πr²`
- 半圆弧长：`πr`
- 半圆周长：`πr + 2r`
- 圆环面积：`πR² - πr²`

### 扇形

小学阶段通常作为圆的一部分理解。

画图规则：

- 标圆心角、半径和弧。
- 如果是半圆、四分之一圆，要明确是圆的几分之几。

常用关系：

- 半圆面积是圆面积的 `1/2`。
- 四分之一圆面积是圆面积的 `1/4`。

### 组合图形

常见问题：求不规则图形面积、阴影面积、剪拼图形。

画图规则：

- 先画整体，再用辅助线分成基础图形。
- 每块图形标上必要尺寸。
- 阴影部分要明确是“整体减空白”还是“几个部分相加”。

常用方法：

- 分割法：把图形分成几个长方形、三角形、梯形。
- 添补法：补成大长方形或大正方形，再减去多余部分。
- 平移法：把零散部分移动拼成规则图形。
- 旋转法：把图形旋转后拼成规则图形。
- 等积转化：等底等高、割补面积不变。

## 图形运动

### 平移

画图规则：

- 保持形状、大小、方向不变。
- 每个对应点移动相同距离。
- 用箭头标平移方向和格数。

解题关注：

- 面积和周长不变。
- 位置变了，形状没变。

### 旋转

画图规则：

- 标旋转中心。
- 标旋转方向和角度，如顺时针 `90°`。
- 对应点到旋转中心的距离不变。

解题关注：

- 形状、大小不变。
- 方向改变。

### 轴对称

画图规则：

- 画对称轴。
- 对应点到对称轴距离相等。
- 连线与对称轴垂直。

解题关注：

- 折叠后能完全重合。

## 立体图形范围

### 长方体

常见问题：棱长总和、表面积、体积、容积、展开图。

画图规则：

- 画成长方体透视图。
- 标长、宽、高。
- 看不见的棱可用虚线。
- 表面积题可画展开图，标出 6 个面。

公式：

- 棱长总和：`(长 + 宽 + 高) × 4`
- 表面积：`(长×宽 + 长×高 + 宽×高) × 2`
- 体积：`长 × 宽 × 高`
- 容积：从里面量长、宽、高后相乘。

### 正方体

常见问题：棱长总和、表面积、体积、展开图。

画图规则：

- 标边长。
- 展开图要有 6 个相同正方形。

公式：

- 棱长总和：`边长 × 12`
- 表面积：`边长 × 边长 × 6`
- 体积：`边长 × 边长 × 边长`

### 圆柱

常见问题：侧面积、表面积、体积、展开图。

画图规则：

- 画上下两个圆和侧面。
- 标底面半径或直径、高。
- 展开图：侧面是长方形，长是底面圆周长，宽是高；再加两个圆。

公式：

- 底面周长：`2πr` 或 `πd`
- 侧面积：`底面周长 × 高`
- 表面积：`侧面积 + 两个底面积`
- 体积：`底面积 × 高`

### 圆锥

常见问题：体积，与等底等高圆柱比较。

画图规则：

- 标底面半径或直径、高。
- 高是顶点到底面圆心的垂直距离，不是母线。

公式：

- 圆锥体积：`底面积 × 高 ÷ 3`
- 等底等高圆锥体积是圆柱体积的 `1/3`。

### 观察物体和三视图

画图规则：

- 明确从前面、上面、左面或右面观察。
- 小正方体组合题可以画格子图。
- 三视图只画能看到的外轮廓，不画被遮挡的内部结构。

解题关注：

- 从不同方向看，形状可能不同。
- 还原立体图形时，要考虑被遮挡的小方块。

## 典型题型规则

### 跑道问题

题型特征：

跑道由两个半圆和长方形的两条长边组成。

画图规则：

- 画一个“体育场形”跑道。
- 两条直道标长方形的长。
- 两个半圆合起来标成一个圆。
- 圆的直径等于长方形的宽。
- 左右两个半圆弧必须向外鼓出，不要画在长方形内部。
- 长方形的宽只作为半圆直径来标注，可以画虚线辅助线，不能当作实线跑道边界。
- 跑道题优先使用固定 SVG 模板，不要每次临时按坐标重新生成不同风格。
- 固定模板采用用户认可的上午版本：紫色粗线体育场形跑道，浅色底卡，上下两条直道都标“长边 60米”，右侧虚线标“宽 50米”，中间文字标“两个半圆合起来 = 一个圆”。
- SVG 图形里的 `stroke`、`fill` 必须使用明确颜色值，如 `#7c3aed`、`#ffffff`、`#e5e7eb`，不要在 SVG 属性里写 CSS 变量或 `color-mix(...)`，避免手机端只显示点和文字。
- 主图和步骤图不要压缩在同一个很小的 SVG 里；主跑道图单独成卡片，下面再用计算卡片展示“一圈直道 60×2”“一圈弯道 π×50”“一圈约 277米”。
- 不再使用只有黑色点位和文字的坐标草图作为最终展示图；坐标 JSON 只作结构数据，最终用户可见图必须是完整跑道轮廓。

解题公式：

- 一圈长度：`长 × 2 + π × 宽`
- 多圈长度：`一圈长度 × 圈数`

示例：

长方形长 `60米`，宽 `50米`，跑两圈：

`一圈 = 60×2 + 3.14×50 = 277米`

`两圈 = 277×2 = 554米`

### 篱笆和围栏问题

画图规则：

- 判断是否“四周都围”。
- 如果靠墙，要少算靠墙那一边。
- 如果有门，要从总长度中减去门宽。

常见公式：

- 四周围长方形：`(长 + 宽) × 2`
- 靠一面墙：通常是 `长 + 宽 × 2` 或 `宽 + 长 × 2`，要看图。

### 铺地砖问题

画图规则：

- 画大面积和小方砖。
- 统一单位后再计算。

解题公式：

- 块数：`总面积 ÷ 每块面积`

### 涂色和阴影问题

画图规则：

- 阴影要和非阴影清楚区分。
- 先判断是“加法求阴影”还是“整体减空白”。

解题方法：

- 阴影面积 = 几个基础图形面积相加。
- 阴影面积 = 大图形面积 - 空白部分面积。

### 切割和拼补问题

画图规则：

- 切割线画虚线。
- 切开后的部分在步骤图中分开画。
- 拼补后要标出新图形的长、宽、底、高。

解题关注：

- 割补前后面积通常不变。
- 周长可能改变，不能默认不变。

### 展开图问题

画图规则：

- 长方体展开图要画 6 个长方形。
- 正方体展开图要画 6 个正方形。
- 圆柱展开图要画 1 个长方形和 2 个圆。

解题关注：

- 表面积对应展开图所有面的面积之和。
- 圆柱侧面展开后，长方形的长是底面周长，宽是高。

## 拍照识别几何图形规则

当用户上传几何题图片时：

1. 先识别题干文字、图形类型、已知标注、未知量。
2. 把图片中的图形转成 `diagram` JSON。
3. 保持顶点、边长、角度、圆心、半径、直径、平行/垂直关系。
4. 如果识别不确定，列出需要用户核对的点。
5. 不要直接假装识别完全正确，必须允许用户确认。

识别输出推荐结构：

```json
{
  "question_text": "识别出的题干",
  "known_conditions": ["条件1", "条件2"],
  "ask": "所求问题",
  "diagram": {"w": 360, "h": 240, "els": [], "aux": []},
  "confidence": 0.8,
  "need_user_confirm": true,
  "notes": ["需要核对的地方"]
}
```

## 公式选择检查

解题前必须检查：

- 求的是长度、周长、面积、表面积、体积还是容积。
- 单位是否统一。
- 图中给的是半径还是直径。
- 高是否是对应高。
- 半圆是否包含直径边。
- 组合图形是相加还是相减。
- 立体图形是求一个面、几个面、全部表面积，还是体积。
- 图形运动后面积/周长是否保持不变。

## 常见错误提醒

- 把圆的直径当半径。
- 把平行四边形斜边当高。
- 梯形面积忘记除以 `2`。
- 三角形面积忘记除以 `2`。
- 半圆周长只算弧长，漏掉直径。
- 跑道问题把两个半圆算成两个完整圆。
- 长方体表面积漏算或多算某些面。
- 圆柱侧面积把高当半径。
- 圆锥体积忘记除以 `3`。
- 单位没有统一就计算。

## 教学语气

- 面向小学生时，用“先看图”“把弯道合起来”“补成一个熟悉的图形”等直观语言。
- 不要只说公式，要解释为什么这样列式。
- 遇到复杂图形，先鼓励：“这题看起来复杂，其实可以转化成我们熟悉的图形。”
- 最后答案要完整，带单位。
