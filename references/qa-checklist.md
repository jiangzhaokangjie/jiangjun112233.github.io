# 生成后检查清单（QA）

每张图生成后逐条核对。命中任一项问题，优先重生成或局部编辑。

## 一、IP 识别（最关键）

- [ ] 当前指定 IP 正确？（**姜老师**=白帽(印字)/黑镜/深裤/男性；**丽丽**=黄帽/黑镜/浅蓝衣/女性）
- [ ] 姜老师戴**白色泳帽（印"四季飞浪游泳培训"）**？白色明显，不是蓝/黄
- [ ] 姜老师戴**黑色泳镜**？框住双眼
- [ ] 姜老师穿**深色泳裤**？不是短裤/长裤/其他
- [ ] 丽丽戴**黄色泳帽**？颜色明显是黄，不是蓝/白
- [ ] 丽丽戴**黑色泳镜**？框住双眼
- [ ] 丽丽穿**浅蓝色泳衣**？不是深色/其他颜色
- [ ] IP 是带细节的写实手绘人物，不是黑色块状剪影

## 二、动作参与

- [ ] 姜老师/丽丽在**做动作**（游泳技术/训练示范），不是站着当装饰
- [ ] 动作来自 `xiaolan-ip.md` 动作库，姿势标准、可当教材
- [ ] 一张图只讲一个核心结构

## 三、画面与风格

- [ ] 背景是**干净纯白**？无网格、无边框、无杂色
- [ ] 黑色手绘线稿，略带手绘感？不是矢量死板线
- [ ] 大量留白，构图不铺满？
- [ ] 批注由叠字脚本叠加：红/橙/蓝中文手写体，文字准确无错字，简短（≤4 处）？
- [ ] 生图画面无意外文字；叠字后中文无错字、无印刷体标题

## 四、禁忌红线（任一命中即重做）

- [ ] 没有 PPT 图表风（柱状图/文本框/箭头流程图）
- [ ] 没有商业插画厚涂/渐变光影
- [ ] 没有幼稚可爱/Q 版/表情包
- [ ] 左上角没有"流程图/常见坑/系统架构图"等类型标题
- [ ] 没有把 IP 画成黑色剪影（那是小黑）
- [ ] 指定丽丽时没有画成男性/白帽/深裤（混淆了两个 IP）
- [ ] 没有残留小黑逻辑（拉线/搬运/漏斗/卡断点）

## 五、比例是 16:9 横版？

- [ ] 交付图为 16:9 横版，可直接放进正文

## 迭代优先级

1. IP 识别点缺失（帽/镜/裤）→ 必重做
2. IP 只是装饰 → 必重做
3. 背景不白 / 太满 / 像 PPT → 重做
4. 生图阶段出现文字 → 重生成无字版；叠字批注错字 → 改 annotations.json 重跑
