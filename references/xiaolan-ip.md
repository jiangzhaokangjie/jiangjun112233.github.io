# 姜老师 IP 设定

姜老师是这套配图体系的视觉主角（默认 IP）。所有配图默认由姜老师"出镜"完成，通过标准游泳技术动作和训练示范来诠释文章内容。稳定、可辨识是第一原则。

> **视觉参考**：`references/assets/jianglaoshi-reference.jpg`（真人原型照片，生成时可对照校准身形与气质）

## 一、外形特征（识别点，缺一不可）

- 性别：男性
- 身份：帅气的专业游泳教练、游泳专项训练示范模特
- 头部：戴**白色泳帽**（紧贴头部，帽面印有 **"四季飞浪游泳培训"** 文字标识）
- 面部：戴**黑色泳镜**（框住双眼，镜片可有轻微反光），沉稳、专注、亲和的表情
- 身体：健硕匀称的男性运动员身材——肩宽背厚、手臂线条清晰、核心紧实（典型专业泳手体格）
- 下身：穿**深色泳裤**（藏青/黑），贴身
- 气质：专业教练范儿——沉稳、有经验感、值得信赖

> 记忆口诀：**白帽（印字）+ 黑镜 + 深裤 + 教练型男**。

He has an athletic, well-built swimmer's physique — broad shoulders, defined arms, strong core — and a calm, confident, approachable expression. ## 三、从参考图提取的关键特征（生成时保持一致）

- **脸型**：轮廓分明，下颌线清晰，面部偏瘦长
- **发型**：短发，头顶有造型纹理（戴白帽时头发完全收进帽内，不露发茬）
- **肩臂**：肩宽明显，手臂肌肉线条清晰但不夸张（参考图中扶池壁姿势可见三角肌与前臂线条）
- **体格**：偏壮实型——不是精干修长，而是"有分量"的教练体型
- **表情基调**：沉稳、平和、略带微笑——不是严肃冷峻也不是夸张热情
- **标志性姿态**：双臂展开扶在池边（参考图姿势）→ 可隐喻"掌控""支撑""从容"

## 四、性格

- 专业、耐心、严谨（教练人设，不是年轻选手）
- 乐于示范，动作标准到可以当教材
- 沉稳、有感染力，不呆板
- 是"教练/导师视角"，不是"滑稽小丑"

## 五、常用道具与场景元素

- 泳池、泳道线、池壁、出发台
- 浮板、脚蹼、呼吸管
- 秒表 / 运动手表、计时器
- 示意杆、动作分解线（手绘辅助线）
- 水花、涟漪（少量，点到为止）

## 六、常见动作库（构图时优先从这里选隐喻）

### 技术示范类
- 自由泳高肘划水示范（侧身，手臂高肘入水）
- 蛙泳收-翻-蹬-夹示范
- 仰泳示范（仰卧，双臂交替）
- 蝶泳海豚腿 + 双臂同步示范
- 流线型滑行示范（双臂前伸夹紧头部）
- 出发跳水示范（出发台前倾蓄力）
- 翻滚转身示范（贴近池壁团身）
- 换气节奏示范（侧头吸气，标"一划一换"）
- 打腿练习示范（扶边/浮板，标"鞭状打腿"）

### 教学互动类
- 纠正学员动作（姜老师示意正确姿势，学员对照）
- 用浮板/脚蹼辅助训练
- 看秒表计时、记录成绩
- 示范"慢动作分解"与"完整连贯"两态

### 状态/隐喻类
- 紧张 ↔ 放松（入水前后）
- 慢 ↔ 快（打腿频率）
- 乱 ↔ 稳（流线型 vs 散架姿势）
- 单人重复 ↔ 形成习惯（刻意练习）
- 双臂展开扶池边（参考图经典姿势）→ 可隐喻"掌控全局""从容支撑""基础扎实"

## 七、禁忌（绝不能画成这样）

- 不能没有**白色印字泳帽**
- 不能没有黑色泳镜
- 不能穿错下装（必须是深色泳裤，不是短裤/长裤）
- 不能画成女性、儿童或幼态
- 不能画成黑色块状剪影（那是小黑）——姜老师是带细节的写实手绘人物
- 不能表情怪异、滑稽、惊恐
- 不能脱离泳池 / 训练场景（除非文章强相关且用户要求）
- 不能堆满商业插画式光影与渐变
