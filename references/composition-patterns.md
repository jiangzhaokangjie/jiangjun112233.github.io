# 构图模式

把文章概念"翻译"成游泳训练示范的视觉隐喻。下面是可复用的结构类型 + 原创隐喻方法 + 反复刻规则。

## 一、结构类型（按文章需求选）

### 1. 单一技术示范
姜老师做一个标准动作，配 1-2 个批注解释要点。
例：讲"专注" → 姜老师流线型滑行，批注"全身一条直线"。

### 2. 对比构图（正确 vs 错误）
左：错误动作（散、乱、歪）；右：姜老师标准动作。中间画对比箭头。
例：讲"姿势重要性" → 左边松散打腿，右边鞭状打腿。

### 3. 流程 / 序列
横向 3-4 个格子，姜老师依次完成阶段动作，像分镜。
例：讲"刻意练习" → 分解动作 → 慢速重复 → 连贯 → 提速。

### 4. 多角色互动
姜老师（示范者）+ 学员 / 教练。姜老师示意正确，对方对照。
例：讲"反馈闭环" → 姜老师示范，学员模仿，旁边计时器反馈。

### 5. 状态变化
同一姜老师两态对比：紧张 ↔ 放松、慢 ↔ 快、乱 ↔ 稳。
例：讲"肌肉记忆" → 初期僵硬 vs 后期流畅。

### 6. 隐喻迁移（高级）
把完全不相关的概念，用一个游泳训练场景完整隐喻。
例：讲"知识内化" → 姜老师从"扶板依赖"到"脱板自由游"。

## 二、原创隐喻方法

每次配图都从当前文章**重新发明**一个隐喻，不要套用旧案例。步骤：

1. 提炼文章核心名词/动词（如：坚持、反馈、分层、拐点）
2. 在 `xiaolan-ip.md` 动作库里找"形状/节奏/关系"最像的那个游泳动作
3. 用"动作姿态 + 批注"把抽象词落地
4. 检查：这张图不写标题，外行也能猜出在讲什么

找不到直接对应时，用"姜老师示范 + 学员对照"或"慢/快两态"兜底。

## 三、反复刻规则（每张图都要刻进脑子）

- 姜老师永远在"做动作"，不是"站着看"
- 动作必须来自游泳技术/训练，不能乱编姿势
- 批注用红橙蓝，且简短
- 白底、黑线、大量留白，姜老师白帽（印字）或丽丽黄帽是画面唯一大面积色块
- 一张图只讲一个结构，不贪多
- 隐喻要"奇怪但成立"——让人会心一笑又觉得准确

## 四、不要做的事

- 不要直接复刻 examples 里的某张构图（只学密度和参与方式）
- 不要用小黑那套"拉线/搬运/卡断点/漏斗"逻辑——那是小黑的，不是姜老师的
- 不要让姜老师承担他不会的工种（如写字、敲代码、修 bug）
