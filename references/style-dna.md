# 风格 DNA

这套配图统一的视觉语言。无论画什么主题，都先符合下面的"不变项"，再让内容变化。

## 一、基础画布

- 比例：16:9 横版（1920×1080 量级），正文中图
- 背景：**纯白**，干净无杂色、无网格、无边框
- 留白：大量留白，构图集中在一侧或中部，不要铺满
- 线条：**黑色手绘线稿**风格，略带手绘抖动感，不是矢量死板线

## 二、角色画法

- 姜老师/丽丽为带细节的写实手绘人物（非黑色剪影、非 Q 版卡通）
- 外形识别点由 `xiaolan-ip.md` 规定：蓝帽、黑镜、深裤
- 身体用黑色线稿勾勒，肌肉/泳衣可用轻量灰阶或排线区分，不要大面积填色
- 姜老师自身颜色仅三处可显色：泳帽白（印字）、泳镜黑、泳裤深；丽丽：泳帽黄、泳镜黑、泳衣浅蓝；其余保持线稿

## 三、批注与文字（生图后叠加）

- 中文批注**不在生图阶段出现**——生图画面必须纯画面（无文字），由 `scripts/overlay_annotations.py` 用系统楷体确定性叠加。
- 少量**红色 / 橙色 / 蓝色**中文手写体批注，像老师改作业的圆珠笔
- 中文要短：关键词、箭头、圈注，不要成句段落
- 一处图最多 2-4 个批注点，宁少勿多
- 字体为系统楷体（手写风），不要印刷体、不要艺术体

## 四、配色纪律（铁律）

| 元素 | 颜色 |
| --- | --- |
| 背景 | 纯白 #FFFFFF |
| 主线条 / 角色 | 黑 #1A1A1A |
| 批注-强调 | 红 #E5484D |
| 批注-提示 | 橙 #F59E0B |
| 批注-信息 | 蓝 #2563EB |
| **姜老师**泳帽 | 白 #FFFFFF（印"四季飞浪游泳培训"文字） |
| **姜老师**泳镜 | 黑 #1A1A1A |
| **姜老师**泳裤 | 深 #1E293B |
| **丽丽**泳帽 | 黄 #FCD34D（基于真人原型） |
| **丽丽**泳镜 | 黑 #1A1A1A |
| **丽丽**泳衣 | 浅蓝 #7DD3FC（基于真人原型） |

除上表外，画面基本为黑白。克制用色是"清爽专业"的关键。

## 五、禁忌（风格红线）

- 禁止 PPT 图表风（柱状图、箭头流程图、文本框）
- 禁止商业插画式厚涂、渐变光影、复杂背景
- 禁止幼稚可爱、Q 版、表情包化
- 禁止左上角加"流程图 / 常见坑 / 系统架构图"等类型标题
- 禁止画面过满、信息过载
- 禁止非手写体的大段中文说明
- 禁止在生图阶段出现任何文字 / 中文 / 标签（批注统一由叠字脚本加）
- 禁止把姜老师/丽丽画成黑色剪影（那是小黑，不是我们的 IP）

## 六、目标观感

一眼望去：白底、黑线、一个帅气专业的姜老师（或丽丽）正在做标准游泳示范、几点红橙蓝手写批注。像一位游泳教练手绘的讲解图，专业但不冰冷，干净但有灵气。
